# Для любого AI-исполнителя

Перед задачей прочитай:

1. `.orchestra/RULES.md`
2. `.orchestra/PROJECT.md`
3. `.orchestra/GIT.md`
4. только назначенный тебе файл из `.orchestra/tasks/`

Выполни только назначенную задачу.

В конце:
- проверь результат;
- сделай commit;
- заполни итог в task-файле;
- остановись.

Не бери следующую задачу самостоятельно и не принимай проектные решения вместо пользователя.
