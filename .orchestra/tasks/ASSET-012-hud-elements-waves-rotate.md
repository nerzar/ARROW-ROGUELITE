## Спецификация

1. **Плашка «следующая волна»** (над пустым подиумом): 512×160, тёмный камень + бронза; слева круглое

2. **Иконка Rotate**: 256×256, стрелка по кругу вокруг квадратной доски, бронза; три состояния —
   доступен / нет зарядов (серый) / подсвечен (magic glow). Сейчас на экране текст «Rotate ×2».
3. **Пипсы зарядов**: 64×64 — полный (бронзовый камень с тёплым светом) и пустой (тёмная выемка);
   по 1–2 под слотом предмета.
4. **Слот предмета**: 256×256 рамка под иконку из ASSET-009; состояния — обычный / hover / активный
   (ожидает цель) / пустой.
