# Доска Arrow-Roguelite

Здесь только работа, которая **сейчас** требует внимания. Подробности активной задачи живут в её task-card. История — в Git и `.orchestra/archive/`.

## База

`main` — сведённый рабочий Prologue baseline. В него влит весь игровой трек: playable Prologue из 5 этапов, Campaign Editor, Pose Editor, species presentation defaults, каталог существ, импорт арен, Goblin King flee intro.

Отдельных task-веток под эту работу больше нет: принятое живёт в истории `main`, неслитые design/docs сохранены тегами `archive/2026-09/*`.

## Следующий шаг

Заранее не фиксируем длинную очередь.

После выбора стрелы её подключают в `main` поверх BUILD-032 как основы renderer'а. Дальше пользователь проходит Prologue и говорит, что менять. Из этого feedback архитектор формулирует **один следующий полезный шаг**.

Если во время playtest найден конкретный дефект — делаем FIX. Если нужно выбрать визуальное направление — сначала показываем вариант пользователю. Если всё работает — только тогда двигаемся дальше по контенту/Act I.

## Правила доски

- Не использовать BOARD как большой backlog или список идей.
- Не хранить здесь DONE-задачи после принятия/архивации.
- Не создавать несколько параллельных задач вокруг одной проблемы без причины.
- Новая задача появляется только когда понятен конкретный следующий результат.
- Для визуальной работы следующий зависимый шаг ждёт просмотра пользователя.
