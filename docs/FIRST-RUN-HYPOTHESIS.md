# Magic Arrow — первый забег (рабочая гипотеза)

> Статус: DESIGN HYPOTHESIS. Это не финальный баланс и не финальный контент. Пользователь подтвердил направление: короткий пролог должен незаметно перейти в первый акт; **направление впервые становится ресурсом на мини-боссе в конце пролога**, и там же игрок впервые получает возможность повернуть центральную фигуру.

## Главная драматургия забега

Старт должен почти не отличаться по сложности восприятия от обычного Arrow/Tap Away.

За один забег игра проходит путь:

`tap away → projectile → mini-boss → direction as resource → Rotate → multi-side combat → Ricochet → projectile transformation → Serpent → Chain → финальная сборка`.

Главный контраст:

- начало: `обычная стрелка → один моб`;
- финал: `Rotate → нужная стрелка → Serpent → hit → Ricochet → Chain → визуальный overload`.

## Главное правило обучения

До мини-босса пролога игроку **не нужно думать о направлении как о ресурсе**.

Первые обучающие encounter'ы используют одну активную сторону арены. Игрок по очереди понимает:

1. как освобождается стрелка;
2. что она не исчезает, а летит дальше;
3. что попадание реально влияет на внешнюю цель;
4. что у цели есть понятное количество попаданий до смерти.

Только после этого мини-босс впервые ломает простое правило и заставляет смотреть на направление.

# PROLOGUE — «Стрелка живёт после поля»

Пролог должен быть коротким и ощущаться не как отдельный tutorial-режим, а как начало настоящего забега.

## Encounter 1 — Первый выстрел

**Арена:** один слабый моб справа.

**Board:** маленький и почти очевидный; активна одна сторона.

Игрок освобождает стрелку. Она:

`выходит из puzzle → получает короткий trail → летит вправо → ударяет моба`.

Цель — без текста показать главное отличие Magic Arrow от обычного Tap Away.

Никаких upgrades, relics, rotation, нескольких сторон или сложных UI.

## Encounter 2 — Стрелку нужно сначала освободить

**Арена:** один моб справа, 2 hit units.

**Board:** несколько стрел блокируют друг друга.

Игрок учится отличать свободную стрелку от заблокированной и видеть последовательность освобождения.

Внешняя цель остаётся только справа. Направление ещё не является задачей.

На первом обучающем отрезке не стоит жёстко наказывать за ошибочный tap: достаточно короткой реакции/отскока/подсветки.

## Encounter 3 — Попадания имеют цену

**Арена:** один более крепкий моб справа, например 3 hit units.

**Board:** маленький, но уже не полностью очевидный.

Задача — показать, что количество оставшихся стрел связано с боем: игрок буквально тратит projectile budget на цель.

Можно впервые показать понятный HP/hit-indicator без сложных чисел.

Направление всё ещё не требует решения.

## Encounter 4 — Mini-boss пролога: Compass Warden / рабочее имя

Это **первый момент, когда направление становится ресурсом**.

### Phase 1 — знакомое правило

Mini-boss находится справа.

Игрок несколько раз бьёт его обычными стрелами и уверен, что уже понял игру.

### Phase 2 — смена стороны

После потери части HP mini-boss меняет позицию или уязвимый сектор, например перемещается наверх.

На board остаются стрелки, но подходящих `↑` мало или они неудобно заблокированы.

Игрок впервые видит проблему:

> у меня есть стрелы, но они смотрят не туда.

### Tutorial reveal — Rotate Board

Именно здесь впервые появляется возможность повернуть центральную фигуру.

Рабочий вариант prototype:

- игра выдаёт один бесплатный `Rotate`;
- игрок поворачивает всю оставшуюся фигуру на 90°;
- геометрия board сохраняется, но все стрелки физически меняют направление относительно внешней арены;
- нужный сектор получает новый запас projectile.

Анимация должна быть короткой, очень читаемой и приятной. Это первая большая `ага`-механика игры.

### Phase 3 — закрепление

Mini-boss ещё раз меняет активный сектор или открывает слабое место с другой стороны.

Игрок уже понимает идею без нового tutorial overlay.

### Награда пролога: Compass Shard / рабочее имя

После победы Rotate становится частью run-kit.

Для первого prototype:

> `1 Rotate charge на encounter`.

Точное правило позже можно менять: cooldown, заряд за убийства, 2 charges, стоимость хода и т.д. Сейчас важнее проверить саму механику.

### Что должен почувствовать игрок

Не «я получил кнопку вращения», а:

> **направление стрел — это запас боеприпасов по сторонам, а Rotate позволяет этот запас перераспределять.**

После этого пролог заканчивается без длинного меню: забег продолжается, начинается Act I.

---

# ACT I — Direction becomes combat

Теперь игра начинает полноценно использовать то, что mini-boss только показал.

## Encounter 5 — Две стороны

Враг справа и враг слева.

Это первый обычный бой, где игрок самостоятельно распределяет стрелы между сторонами.

Rotate уже доступен как часть набора, но encounter должен быть решаем и без идеального использования.

После победы — **первый настоящий 1-of-3 minor upgrade draft**.

Кандидаты:

- `Heavy Arrow` — ограниченный усиленный hit;
- `Pierce I` — projectile проходит в следующую цель;
- `Gold Arrow` — часть попаданий создаёт дополнительную награду.

Первый draft появляется только после того, как core loop уже понятен.

## Encounter 6 — Третья сторона + временная цель

Основной враг справа/слева.

Сверху появляется сундук, кристалл или другой reward-target на `N moves`.

Нужная стрелка существует, но доступ к ней требует изменить порядок разбора board.

Теперь выбор:

- продолжать эффективный damage;
- потратить несколько ходов ради временной награды;
- при необходимости использовать Rotate для перераспределения направлений.

Это первая серьёзная связка puzzle + внешняя арена.

## Encounter 7 — Elite: Directional Shield

Elite имеет простую читаемую защиту:

- уязвим только с конкретной стороны;
- или shield периодически закрывает один сектор.

Не вводить отдельную кнопку атаки. Всё управление по-прежнему происходит через выбор стрелки на board.

После победы — второй upgrade draft.

Здесь можно впервые добавить в пул:

- `Split`;
- `Freeze`;
- `Burn`;
- `+1 Rotate charge`;
- усиление выбранного minor effect.

## Encounter 8 — Boss I: Twin Guardian / Ricochet Keeper

Первый полноценный босс первого акта.

Рабочая структура:

- две связанные цели на разных сторонах;
- либо одна сущность с двумя уязвимыми секторами;
- игроку выгодно управлять распределением направлений и Rotate;
- нельзя сводить бой к большому HP-bar.

### Boss reward: Ricochet Core

После победы:

> после первого попадания projectile ищет вторую допустимую внешнюю цель.

Для первого демонстрационного run награда гарантированная.

С этого момента одна правильно выбранная стрела начинает решать сразу несколько задач.

# ACT II — Стрела начинает мутировать

## Encounter 9 — Ricochet showcase

Две близкие цели специально расставлены так, чтобы новый Ricochet сразу выглядел полезно и красиво.

Никакой новой системы. Игроку дают несколько минут кайфа от награды босса.

## Encounter 10 — Давление с трёх сторон

Несколько слабых целей + одна более важная + временный reward-target.

Игрок комбинирует:

- выбор свободной стрелки;
- направление;
- Rotate;
- Ricochet;
- приоритет внешних целей.

После победы — draft/relic choice.

## Encounter 11 — Elite: геометрическая защита

Элита заставляет использовать уже знакомые системы необычным способом.

Кандидаты:

- бронирована с двух сторон из трёх;
- вызывает слабых мобов по соседним секторам;
- временно блокирует один сектор;
- меняет уязвимую сторону после попадания.

Никакой новой кнопки.

## Encounter 12 — Boss II: Serpent Queen

### Phase 1

Обычный directional бой.

### Phase 2 — visual/mechanical shift

Босс меняет правила projectile:

- свет/фон переходят в другую визуальную фазу;
- стрелы после выхода из board начинают превращаться в магических змей;
- траектория становится живой;
- Serpent получает реальное механическое свойство: homing, огибание простого препятствия или другой вариант.

Важно: это не skin. Игрок должен почувствовать изменение поведения projectile.

### Boss reward: Serpent Form

После победы часть механики остаётся до конца run.

Точный trigger не фиксируем. Кандидаты:

- каждая N-я стрела;
- стрелы после Ricochet;
- стрелы определённого направления;
- ограниченный proc chance.

# ACT III — Build начинает ломать правила

## Encounter 13 — Serpent + Ricochet + Chain seed

Encounter специально показывает синергию двух boss powers.

Рабочая цепочка:

`arrow exits board → Serpent transform → hit → Ricochet → second hit`.

В конце encounter или через relic choice игрок может получить `Chain Lightning`.

Chain должен быть заметным новым поведением, а не скрытым процентом урона.

## Encounter 14 — Build showcase

Много слабых целей, одна элита, несколько активных сторон и короткая временная награда.

Это не новый урок. Это encounter, где игроку разрешают почувствовать, что его сборка начинает быть «нечестной».

Допустимая визуальная эскалация:

- trails;
- glow;
- hit flash;
- ricochet arcs;
- serpent motion;
- chain lightning;
- частицы;
- лёгкий shake;
- короткие hit-stop акценты.

## Encounter 15 — Final Boss: Magic Core / рабочее имя

Финальный босс проверяет весь язык игры.

### Phase 1 — Direction

Босс/его части меняют уязвимую сторону.

### Phase 2 — Geometry

Один или несколько секторов временно блокируются/становятся невыгодными. Rotate позволяет перераспределить оставшийся board.

### Phase 3 — Overload

Визуальная кульминация:

- dark/neon shift;
- несколько внешних целей/частей босса;
- Ricochet реально экономит projectile budget;
- Serpent заметно меняет траектории;
- Chain связывает цели;
- Rotate остаётся осмысленным, а не декоративным.

Финальная желаемая последовательность:

`Rotate → нужная стрелка → Serpent → hit → Ricochet → second target → Chain Lightning → сильный feedback`.

# Ритм выдачи систем

| Момент | Новая мысль |
|---|---|
| Prologue 1 | стрелка летит дальше поля |
| Prologue 2 | стрелку нужно освободить |
| Prologue 3 | попадания — ограниченный ресурс |
| Prologue mini-boss | направление впервые становится ресурсом + Rotate |
| Act I | multi-side combat и временные цели |
| Boss I | permanent Ricochet |
| Act II | projectile synergies |
| Boss II | Serpent Form |
| Act III | Chain + build showcase |
| Final Boss | все системы одновременно |

# Prototype content budget

Для проверки этого run достаточно:

- 3 базовых enemy archetype;
- 2 elite modifier;
- 1 prologue mini-boss;
- 3 полноценных boss encounter включая финал;
- Rotate;
- Ricochet;
- Serpent Form;
- Chain Lightning;
- 4–6 minor upgrades/relics;
- 1 временная reward target;
- 1 базовый biome + 1–2 visual phase shifts.

Не производить десятки мобов до proof-of-fun.

# Что prototype обязан доказать

1. Первый tap с projectile уже приятнее обычного Tap Away.
2. Пролог объясняет core без длинных текстов.
3. Mini-boss создаёт момент `ага: направление — ресурс`.
4. Rotate ощущается сильным инструментом, но не убивает puzzle.
5. Multi-side arena меняет порядок разбора board.
6. Ricochet/Serpent/Chain дают качественно разные ощущения.
7. К финалу сборка ощущается созданной игроком, а не просто набором процентов.
8. Визуальная эскалация не ломает читаемость центрального puzzle.

# Пока не фиксируем

До prototype/market validation остаются открытыми:

- точное число Rotate charges;
- является ли Rotate бесплатным действием или тратит move;
- точные HP/hit-units;
- точные проценты/триггеры эффектов;
- финальные названия мобов и боссов;
- конкретный fantasy wrapper;
- длина полноценного коммерческого run;
- сколько directional sectors реально удобно на телефоне: 3 или 4.
