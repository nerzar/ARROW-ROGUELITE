VIS-011 — Arrow Arena Mockups

Один и тот же board, одна камера, одни logical paths — три визуальных языка (B — primary, C — fallback, A — опциональное сравнение). Spec: docs/VIS-010-ARROW-PRESENTATION.md. Только мокап — runtime (board-renderer.js, projection, gameplay, calibration) не тронут.

Клетки не пересекаются (21/25 занято, свободны (3,0) и (4,0) — воздух в углу). Соседние paths специально идут рядом: long↔hover у правого края, hit↔pin↔blocked вверху-слева — проверка «не каша».

Вариант B — Engraved Groove + running pulse primary proposal

  • Тело — тёмная гравированная канавка (0.30S) + нить золота внутри (0.07S). Ничего не выходит за коридор ±0.55S.
  • blocked — пустая резьба без нити; free — нить статична; hover — один pulse бежит к голове; pin — разрыв нити под камнем.
  • firing — яркий отрезок срывается за край, канавка гаснет от хвоста; hit — вспышка дна у головы (~200 мс).

Вариант C — Solid Core + sparse direction markers fallback

  • Тело — тонкий матовый стержень (0.20S, ноль glow), направление — ≤3 шевронов + кайт-наконечник.
  • blocked — alpha 0.45 (пунктир упразднён); hover — плоская фаска-плашка + золотые шевроны; firing — стирание от хвоста.
  • Минимальное отклонение от текущего рендера — самая дешёвая реализация.

Вариант A — Segmented Rail опционально

  • Тело — ряд каменных плашек (0.34S, зазор 0.16S), сужаются к голове. Включён: на длинной winding-стрелке зазоры — единственное сравнение, показывающее дробление path против сплошных B/C.
  • hover — золотой марш по звеньям; firing — гаснущие звенья от хвоста; dead-логіка не показана (все стрелки живые — композиция).

Как смотреть (8 core requirements из задачи): 1) направление мгновенно? 2) длинная читается? 3) соседи не каша? 4) free vs blocked без текста? 5) наконечник заметен, < половины клетки? 6) перспектива сохранена (верх тоньше)? 7) у firing понятно направление? 8) FX не прячут соседей?
