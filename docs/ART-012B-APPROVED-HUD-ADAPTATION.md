## Архитектура решения и композиция

В отличие от прототипа, где черновой Player HUD занимал левый край, а черновой переключатель Rotate лежал прямо по центру под каменной доской (перекрывая алтарный ромб и булыжниковый пол), утверждённый язык референса реализует естественное разделение внимания:

```
+-----------------------------------------------------------------------------------+
|  [Чистая ночная сцена замка, луна, водопады, факелы — БЕЗ верхнего RPG-бара]     |
|                                                                                   |
|                   [Dire Wolf 1 (Подиум над доской)]                               |
|                     [ 💀 Dire Wolf   ⏱ 3 ]                                        |
|                     [==== 3 / 3 ========]                                         |
|                                                     [Dire Wolf 2 (Правая лестница)]
|               +-----------------------+               [ 💀 Dire Wolf   ⏱ 4 ]     |
|               |  КАМЕННАЯ ДОСКА       |               [==== 2 / 2 ========]       |
|               |  (100% нетронутый     |                 (Волк на ступенях)        |
|               |   puzzle core:        |                                           |
|               |   золотые стрелы)     |                                           |
|               +-----------------------+                                           |
|                                                                                   |
|                         [◇] (Алтарный ромб открыт)                                |
|  [PLAYER HUD]                                                 [ACTIONS DOCK]      |
|  (Портрет Героини) [❤️] [=== 10/10 ===]                      (🔄 Rotate) [🏹 1] [❄️ 2]
|  [🔹 🔹 ◈]                                                                        |
+-----------------------------------------------------------------------------------+
```

### 1. Player HUD (левый нижний угол)
- **Портрет героини**: Круглый медальон с портретом в изумрудном капюшоне, обрамлённый резным золотым и зелёным кольцом. Частично заходит на каменную плашку, создавая объёмное наслоение.
- **Сланцевая подложка**: Тёмно-серый полированный камень (`#16181d`) с микро-фасками и угловыми скосами.
- **Индикатор здоровья**:
  - Рубиновое объёмное сердце с золотым контуром.
  - Скошенный рубиновый бар с вертикальным градиентом и сочной подсветкой: `10 / 10`.
  - Читаемый serif-шрифт Marcellus / Georgia с глубокой чёрной обводкой для мгновенной читаемости в пылу боя.
- **Слоты кристаллов / маны / зарядов**: 3 ромбовидных кристалла (2 активных сияющих лазурных кристалла `#00aaff` с белым бликом + 1 пустой слот в бронзовой оправе).

### 2. Actions Dock (правый нижний угол)
- **Rotate Control**:
  - Круглый золотой диск с радиальным теплым янтарным свечением.
  - Внутренние круговые стрелки против/по часовой стрелке.
  - Чёткая подпись `Rotate` в античном стиле Cinzel/Trajan.
- **Item Slot 1 (Active Weapon)**:
  - Резной круглый безель с серебряным силуэтом лука.
  - Индикатор зарядов в бронзовом кружке: `1`.
- **Item Slot 2 (Consumable / Ability)**:
  - Резной круглый безель со светящимися лазурными морозными кристаллами (Frost Darts).
  - Индикатор зарядов: `2`.
- **Платформа**: Весь блок сидит на едином сланцевом цоколе, гармонично сливающемся со ступеньками и каменным основанием арены.

### 3. Enemy HUD Plates (над подиумами врагов)
- Сохранены на их штатных позициях над подиумами Dire Wolf (над верхним подиумом и над правыми ступенями).
- **Сланцевый верхний шильдик**:
  - Тёмно-бордовый сланцевый фон с акцентной рамкой.
  - Алая иконка черепа/зверя.
  - Имя монстра `Dire Wolf`.
  - Выделенный бейдж таймера атаки с контрастным фоном: `⏱ 3` (верхний) и `⏱ 4` (правый).
- **Рубиновый HP-бар**:
  - Скошенная геометрия с золотисто-рубиновым кантом.
  - Плотное рубиновое заполнение со значениями `3 / 3` и `2 / 2`.

## Строгое соблюдение ограничений

- [x] **Арена не тронута**: Водопады, башни ночного замка, полная луна, факелы, знамёна сохранены с исходного live screenshot.
- [x] **Board не тронут**: Каменная текстура плиты, трещины, замшелость и все золотые стрелы идентичны оригиналу.
- [x] **Враги и подиумы не тронуты**: Позиции, позы и масштаб волков 100% сохранены.
- [x] **Никакого RPG-мусора**: Полностью отсутствуют верхние топ-бары с золотом/гемами, счётчики уровней, чужеродные кнопки «End Turn», боковые сайдбары или инвентарные сетки.
- [x] **Результат**: Ровно один утверждённый, завершённый вариант в целевом разрешении 1280×720.
