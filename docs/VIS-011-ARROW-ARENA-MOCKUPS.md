## 2. Честность сравнения (одна композиция на всех)

Во всех трёх панелях одни и те же 6 logical paths (клетки disjoint, 21/25, свободны (3,0),(4,0)):

| Стрелка | Клетки | Выход | Состояние |
|---|---|---|---|
| long | (0,4)→(1,4)→(1,3)→(2,3)→(2,2)→(3,2)→(3,1)→(4,1) | EAST | free, длинная winding (8 клеток) |
| blocked | (0,0)→(1,0)→(2,0) | NORTH | blocked |
| hover | (4,4)→(4,3)→(4,2) | NORTH | hover / selected |
| pin | (0,1)→(0,2)→(1,2) | EAST | Stone Pin, 2t |
| fire | (3,3)→(3,4) | SOUTH (за нижний край) | firing, снаряд уходит за board |
| hit | (1,1)→(2,1) | EAST | hit / impact на голове |

Соседства для проверки шума подобраны специально: long↔hover идут параллельно у правого края
(голова long (4,1) рядом с головой hover (4,2)); hit зажат между blocked сверху и pin снизу.
Наконечник везде — кайт `0.55S × 0.62S` по drawn-направлению (угол выхода, не логический сегмент),
`S` — перспективный масштаб клетки головы. Ноль `shadowBlur` вдоль тел во всех вариантах.
Каменные бирки состояний на board — только навигация по мокапу, не предложение runtime-UI.

Вариант A включён сознательно: на длинной winding-стрелке только он показывает дробление path
зазорами против сплошных B/C — это полезное сравнение, а не третий радиус третьего.

## 3. Оценка B — Engraved Groove + running pulse

- **Direction readability:** мгновенно. Три дублирующих маркера: нить ведёт глаз, шеврон у головы,
  кайт с золотой режущей кромкой. Pulse в hover/firing бежит строго к голове.
- **Long-path readability:** сильная. В покое канавка почти исчезает в плите (два тона);
  8-клеточная winding-стрелка не превращается в лапшу — вести взгляд нечему, кроме нити `0.07S`.
- **На камне:** strongest из трёх — выемка, а не наклейка. Кромка канавки работает и на светлом песчанике `5x5-good`.
- **Free vs blocked:** без текста, самый контрастный из трёх: нить есть (заряжена) / пустая резьба (не заряжена).
- **Noise 5×5:** минимальный. В статике движется только hover-pulse; соседние канавки long/hover не сливаются
  (между осями ≥1.0S, коридор эффектов ±0.55S соблюдён).
- **Noise 6×6 (ожидание):** лучший прогноз — тишина масштабируется: уже канавки тоньше относительно шага,
  нить `0.07S` остаётся внутри. Риск — на мелкой клетке фаска канавки съестся (см. главный риск).
- **Implementation complexity:** средняя. Тот же polyline + два прохода ширины + dash-нить + один `animateMotion`-эквивалент;
  разрыв нити под пином — два partial-сегмента вместо одного.
- **Главный риск:** на светлой теме и мелких клетках тёмная канавка может читаться тяжелой/грязной;
  лечится глубиной фаски, не шириной — проверить глазами на 6×6 перед кодингом.

## 4. Оценка C — Solid Core + sparse direction markers

- **Direction readability:** мгновенно. Шевроны (≤3, у хвоста/середины/головы) + кайт; на hover/head-шевроне золото.
- **Long-path readability:** средняя. Стержень `0.20S` тоньше нынешнего, но остаётся сплошной линией через 8 клеток —
  winding читается, но «ведёт» сильнее B (лекарство слабее: тонкость вместо тишины).
- **На камне:** слабее B — стержень лежит НА плите. Матовость и отсутствие glow спасают от «стикера», но инкрустации нет.
- **Free vs blocked:** без текста читается (alpha 1.0 кость vs 0.45 камень), но тише пары «нить есть/нет» у B.
- **Noise 5×5:** низкий. Шевроны редкие, подложка hover — плоская плашка без размытия; long↔hover рядом не сливаются,
  но два параллельных стержня заметнее двух канавок.
- **Noise 6×6 (ожидание):** приемлемый. Шевроны масштабируются числом (на коротких — 1), стержень уже канавки B;
  риск — шевроны на извилистых paths требуют расстановки по длине дуги, иначе встанут криво на изгибе.
- **Implementation complexity:** низкая. Минимальная дельта от текущего рендера: убрать `shadowBlur`/inner-core/пунктир,
  добавить шевроны по arclength. Самый дешёвый и безопасный путь.
- **Главный риск:** самый слабый «каменный» характер — пользователь уже отверг line-look как класс;
  C ближе всех к отвергнутому (линия, пусть тихая). Может проиграть именно по ощущению, а не по читаемости.

## 5. Оценка A — Segmented Rail (опциональная)

- **Direction readability:** мгновенно (сужение сегментов к голове + кайт + марш).
- **Long-path readability:** сильная, другим способом: зазоры дробят winding на ритм, лапши нет.
- **На камне:** средне — инкрустация, не выемка; на песчанике смотрится органично, но «механичнее» B.
- **Free vs blocked:** без текста (фаска/свет vs плоские + широкие зазоры), читается хорошо.
- **Noise 5×5 / 6×6:** низкий на 5×5; на 6×6 главный риск из трёх — сегменты сливаются в линию,
  нужен минимальный зазор `max(0.16S, 1.5px)`, на мелких клетках плашки превратятся в пунктир-кашу.
- **Implementation complexity:** средняя-высокая. На стрелку ~длина/0.5S примитивов + раскладка по arclength
  с учётом перспективы (сегменты сужаются и к голове, и вдаль).
- **Главный риск:** стиль «рельса» может спорить с organic-фэнтези арены; самый дорогой вариант при спорной выгоде
  поверх B. Держать как второй финалист, только если B покажется слишком тихим для core-механики.

## 6. Сравнение одной строкой

| Критерий | B — Groove | C — Core | A — Rail |
|---|---|---|---|
| Направление мгновенно | да (нить+шеврон+кайт+pulse) | да (шевроны+кайт) | да (сужение+кайт+марш) |
| Длинный path | **тишина** | тонко, но сплошная | **зазоры** |
| Часть камня | **выемка** | лежит сверху | инкрустация |
| Free vs blocked без текста | **нить есть/нет** | alpha 1.0/0.45 | фаска/плоские |
| Шум 5×5 | минимальный | низкий | низкий |
| Прогноз 6×6 | лучший (тишина масштабируется) | приемлемый (шевроны по дуге!) | рискованный (слияние сегментов) |
| Цена реализации | средняя | **низкая** | средняя-высокая |
| Главный риск | тяжёлая канавка на светлой/мелкой | похож на отвергнутый line-look | рельс vs фэнтези + цена |

Проверка 8 core requirements из задачи на мокапе: направление — у всех трёх мгновенно;
длинная читается — B и A сильно, C средне; соседи не каша — коридор ±0.55S везде;
free/blocked без текста — везде, сильнее всего B; наконечник ≤0.62S — везде;
перспектива — конструкцией (S 42.8→51.6); у firing направление задаёт снаряд за край — везде;
FX соседей не прячут — вспышки только у своей головы.

## 7. Recommendation FOR PLAYTEST (не решение)

Primary для следующего шага — **B**: единственный выполняет главный пункт («часть камня»)
конструкцией, даёт лучшую пару free/blocked и лучший прогноз на 6×6. Fallback — **C**,
если B глазами проиграет на светлой теме/мелких клетках или сроки потребуют дешёвого пути.
**A** — второй финалист, если B покажется слишком тихим для core-механики.

Что нужно от пользователя, чтобы двинуться к renderer-таску: выбрать primary (B/C/A),
подтвердить токены VIS-010 §1.2–§1.3 (кайт `0.55S×0.62S`, коридор `±0.55S`) и ответить,
допустим ли pulse в hover на мобайле (тап-превью) или hover там статичен.
**FINAL APPROVAL = USER ONLY.**
