# `_candidates` — BESTIARY-001 draft manifests (data only)

Each `*.json` maps `magicarrowassets/creatures/<species>` source filenames to
`assets/enemies/<species>/` runtime filenames for one SHORTLIST pack.

- No PNGs are copied here.
- Nothing here is imported by any loader (`assets.js`, `app.js` untouched).
- Wiring a pack into the runtime is a separate future task.

See `docs/BESTIARY-001-ASSET-INVENTORY.md` for the full intake.
