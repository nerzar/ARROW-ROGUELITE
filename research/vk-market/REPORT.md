## Этап 0 — калибровка `members_count`

Файл: [metric-calibration.csv](metric-calibration.csv). Входные UI-данные: `tools/vk_market/calibration_ui_sample.json`.

Методика:
- 23 игры от `1K` до `34M` игроков вручную считаны с публичной страницы https://vk.ru/games без входа (2026-09-16 16:27 UTC).
- `app_id` взят из ссылки карточки (15 шт.) или по точному уникальному названию в `apps.get` (8 крупных карточек без ссылки на app).
- UI показывает число, округлённое максимум до 2 значащих цифр. Правило округления неизвестно, поэтому допустимый интервал `[v − unit/2, v + unit)` покрывает и отбрасывание, и математическое округление.
- `members_count` взят из snapshot-запросов `apps.get`, 16:41–16:49 UTC, то есть на 15–22 минуты позже UI.

Результат:
- **23 из 23** значений `members_count` лежат внутри интервала округления UI-метки;
- отношение `members_count / UI` в медиане 1.01, диапазон 0.971–1.731;
- отношения больше 1.1 встречаются только у однозначных меток (`1M` = 1 730 707, `2M` = 2 749 985 и 2 406 627, `4K`, `6K`, `1K`). Для однозначных меток UI, по наблюдению, отбрасывает дробную часть; двузначные ближе к математическому округлению (`34M` = 33 914 168, `750K` = 748 011).

Что установлено: на выборке 1K–34M `members_count` не противоречит UI-метке «N игроков» с точностью до округления UI.
Что **не** установлено:
- что это одна и та же величина, а не две близкие: UI даёт только 2 значащие цифры;
- что именно считает метрика (накопленные установки, активные пользователи за период и т. п.): API и UI этого не описывают;
- что это MAU: поля MAU в ответах нет.

## Ограничения

1. **Покрытие 4 985 из 5 029–5 030 по `count`.** Через 6 сортировок и 7+ повторных проходов достижимы только 4 985 id. Разница ~45 соответствует недостаче на коротких страницах. Документированного способа добрать эти приложения не найдено.
2. **Ранги на глубине нестабильны** (`popular`, `popular_today`): страницы одной сортировки снимаются в разные моменты.
3. **`members_count` откалиброван только на совпадение с UI-меткой.** Что он измеряет, не установлено; MAU в API нет.
4. **`apps.csv` без полного текста описаний и URL изображений.** С ними файл превысил бы лимит 5 MB в несколько раз (оценка >20 MB). Полные данные лежат только локально в `artifacts/vk-market/20260916T163154Z/export/apps_full.csv` и raw JSON. В коммитимом файле — `description_len`, `screenshots_count`, флаги наличия изображений.
5. **`author_owner_id > 0` и `author_url`** у 807 приложений указывают на аккаунт пользователя-автора. Это публичная метаинформация приложения, сохранена по списку полей задачи.
6. Один snapshot — это состояние на момент сбора. Для трендов нужны повторные snapshot.
7. В BUILD-001 `groups.getMembers` и демография не собирались.
