# Arrow-Roguelite

**Рабочее название проекта.** Старое имя `Magic Arrow` считается устаревшим рабочим названием той же игры.

HTML5-игра под VK Games / VK Mini Apps с возможностью дальнейшей адаптации под другие web-площадки.

## С чего начинать

Главная точка входа в замысел игры:

- `docs/GAME-CONCEPT.md` — канонический краткий концепт, текущие согласованные идеи, открытые вопросы и границы для AI-агентов.

Подробности:

- `docs/FIRST-RUN-HYPOTHESIS.md` — пролог, mini-boss с Rotate, первый run, Ricochet, Serpent, Chain;
- `docs/CONTENT-SYSTEM.md` — мобы, боссы, Arrow Forms, relics, hit-units и data-driven content;
- `docs/DESIGN-HYPOTHESES.md` — расширенные design-гипотезы и референсы;
- `docs/AUDIENCE.md`, `docs/RESEARCH-NOTES.md`, `docs/VK-DATA-PLAN.md` — рынок и аудитория VK.

## Игра одной фразой

**Arrow/Tap Away puzzle, где освобождённая стрелка не исчезает за краем поля, а становится реальным снарядом и продолжает бой во внешней арене; по ходу забега игрок превращает обычные стрелки в всё более сильное и зрелищное оружие.**

Базовая дуга первого proof-of-fun:

`Tap Away → projectile → mini-boss → direction as resource → Rotate → multi-side combat → Ricochet → Serpent → Chain → build showcase → final boss`.

## Текущий статус

Стадия: **product design + technical spike**, а не полноценный production-MVP.

Сейчас параллельно:

- продолжается исследование VK Games;
- уточняется аудитория/тема;
- проверяется готовая open-source база Arrow generator/solver;
- проектируется pure puzzle core;
- готовится proof-of-fun первого run;
- оценивается production pipeline ассетов/VFX.

Ни одно архитектурное, продуктовое, игровое или визуальное решение не считается окончательно принятым без явного подтверждения пользователя.

## Главное отличие

Мы не хотим делать ещё один обычный Tap Away.

После выхода с board стрелка:

- продолжает полёт;
- попадает во врага/босса/сундук/временную цель;
- связывает своё направление с расположением целей вокруг board;
- может получить Ricochet, Pierce, Split, Serpent, Chain и другие формы;
- через Rotate позволяет игроку перераспределять запас направлений.

Boss fights должны менять правила, а сильные boss rewards — позволять часть этих правил забрать себе на оставшийся run.

## Производственные ограничения

- программирование активно делегируется AI-агентам;
- дорогие модели используем для важных решений, большой механический контекст можно отдавать более дешёвым агентам;
- нельзя строить art pipeline на сотнях дорогих уникальных изображений;
- визуальное качество планируется получать через переиспользуемые ассеты, слои, particles, trails, glow, procedural VFX, tweens и shaders;
- generator/solver должны быть детерминированными и проверяемыми;
- чужой код используется только при подтверждённой лицензии; проекты без разрешающей лицензии — только reference.
